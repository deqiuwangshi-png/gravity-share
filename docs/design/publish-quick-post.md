## 一、定稿结论（用户拍板）

**保留双入口，明确分工：**

| 入口 | 定位 | 价值 |
|---|---|---|
| **A · 推荐好东西** | 随手写，三秒发布（发朋友圈/推文心智） | 满足"随手发布"需求，**降低冷启动门槛** |
| **B · 推广外链（带分佣）** | 服务确实想推广/引流/分销的用户 | 清晰展示推广条件，**法律合规保护**（避免金钱纠纷） |

## 二、入口 A：推荐好东西（沉浸式，最终形态）

```
┌──────────────────────────────┐
│  发布动态             ×       │
│                              │
│  说几句推荐语，或直接粘贴      │
│  链接...                     │  ← 单个宽大多行文本区（无边框）
│                              │
│          [ 发布 ]            │  ← 底部唯一主按钮
└──────────────────────────────┘
```

**最终形态（用户拍板）**：
- **沉浸式对话/发朋友圈布局**：单个宽大 textarea（占位符「说几句推荐语，或直接粘贴链接...」），无多个带标题/边框的输入框；
- **外链不单独占一行**：用户直接把链接粘贴进文本区，发布时自动提取 URL 为外链；
- **底部只有【发布】一个主按钮**；
- **白色扁平卡片**：去掉粗灰边框，轻盈扁平；
- **无灰字引导文案**（上一版灰字提示不采用）；
- #标签：文本内 `#xxx` 自动提取为 tags（无单独标签输入框）。

## 三、入口 B：推广外链（带分佣，合规保护）

```
┌────────────────────────────────┐
│  推广外链（商业）      [推广] ×  │
│  [ 推广文案/正文             ]  │
│  [ 推广链接 * https://…     ]  │  ← 强制
│  [#标签]                       │
│  推广类型：[返佣][订阅分成]      │  ← chips
│            [付费课程][积分活动]  │
│  佣金条件 *：[分享得 30% 分佣]  │  ← 强制，清晰展示推广条件
│  走正规流程发布推广，平台将加     │  ← 金色合规声明
│  官方标识（转化率更高）；交易     │
│  风险请自行判断。               │
│  [          发布推广         ]  │
└────────────────────────────────┘
```

字段：正文 + 推广链接（强制）+ #标签 + **推广类型**（必选：返佣/订阅分成/付费课程/积分活动/**其他**）+ **佣金条件**（必填）。

## 四、发布即标注（入口 B 强制，核心机制）

走入口 B 发布的内容，**前端展示时系统强制盖官方标识（徽标式，无左侧竖条）**：

```
┌──────────────────────────────────────┐
│ [返佣]      [⚠ 推广]                  │ ← 类型标签 + 官方徽标（卡片顶部）
│ 邀请好友注册 3D 建模平台，双方各得…     │
│ 返佣 20% · 交易在原平台完成 · 风险自行判断 │ ← 佣金条件 + 风险提示
└──────────────────────────────────────┘
```

| 机制 | 呈现 | 作用 |
|---|---|---|
| 类型标签 | 金色小标：按推广类型显示「返佣 / 分成 / 课程 / 积分 / 其他」 | 一目了然推广性质 |
| 官方徽标 | 红色系「⚠ 推广」 | 合规避险 |
| 风险提示 | 佣金条件 + 「交易在原平台完成 · 风险自行判断」 | C 端保护 |
| 双向价值 | B 端：正规流程 → 官方标识 → 转化率更高；C 端：见标识知推广 → 风险自行判断 | 信任背书 + 合规 |

> 补充（可选 P1）：入口 A 发布时做关键词检测（返佣/邀请/下载/注册/优惠），命中显示轻量「含推广引导」提示并引导转入口 B——本期不强制，避免复杂度。

## 五、数据模型

```ts
interface DiscoveryItem {
  content: string;          // 正文合一（A/B 通用）
  url: string;              // 外链（强制）
  tags: string[];           // #标签
  commercial?: boolean;     // true = 走入口 B 发布（强制标识依据）
  promoType?: string;       // 推广类型：返佣/订阅分成/付费课程/积分活动（B 专属）
  commission?: string;      // 佣金条件（B 专属，必填）
  // 原 title/description 由 content 承接（title 取首行截断）
}
```

- `commercial: true` → 卡片渲染强制官方标识（左侧竖标 + ⚠ 徽标 + 佣金条件）
- mock 数据：`discoveryItems` 现有「开发者 VPN 推荐」（commercial）补充 promoType/commission 样例
