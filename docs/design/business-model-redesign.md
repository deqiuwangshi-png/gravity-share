# 引力核心业务模型与产品设计 · 方案

> 版本：v1.0（待评审）· 日期：2026-08-21
> 产品名：**引力** · 主张：**让好东西有地方摆，让有需求的人找得到**

---

## 一、产品定位（一句话）

> **引力不是一个内容平台，而是"好东西的外溢展示层"——任何平台的好东西，都可以摆到引力上被陌生人发现，点击回流原平台完成交易与交付，引力只负责秩序与展示。**

三个关键词：
- **外溢**：解决内容"存在但无法被陌生需求者看到"的封闭问题；
- **展示层**：引力不生产内容、不托管内容、不参与交易，只做展示与连接；
- **秩序**：商业内容强制透明标注，平台声明免责边界，交易永远回流原平台。

---

## 二、业务闭环

```
[生产平台] 微信/知乎/CSDN/FlowUs/个人博客/推广活动（内容封闭、流量受限）
    │ ① 用户把内容外链「摆」上引力（发布）
    ▼
[引力 展示层] 发现流 · 分类 · 广场交流 · 商业透明标注 · 秩序审核
    │ ② 陌生需求者发现 → 点击「查看」
    ▼
[回流原平台] 交易 / 订阅 / 下载 / 返佣——全部在原平台完成
    │ ③ 引力声明：不参与交易，只负责秩序与展示
    ▼
[用户收益] 内容获得陌生流量 · 佣金找到转化人 · 影响力外溢
```

**引力在闭环中的不可替代性**：生产平台没有"跨平台发现"的场景，用户社交圈没有"陌生需求者"，引力是两者之间的唯一展示面。

## 三、用户价值映射（对应每一条痛点）

| 用户场景 | 引力解法 |
|---|---|
| 微信文章 → 只能微信内流量 | 摆上引力 → 跨平台被陌生人发现 |
| 知乎 / CSDN 内容封闭 | 统一外链展示，无平台隔离 |
| 个人博客没人看 | 博客内容获得展示位与自然流量 |
| FlowUs 付费专栏 30% 分佣找不到人 | 发布为「商业推广」内容，透明标注，陌生人按需点击 |
| VPN 邀请注册 10% 佣金找不到客户 | 同上，精准触达有需求者 |
| 3D 建模邀请订阅 20% 佣金人太少 | 同上 |
| 邀请下载 trae 双方得积分、社交圈小 | 同上，扩大触达半径 |
| 教程被动转发、无法有效转化 | 主动发布 + 详情页转化路径 |
| 内容价值封闭（存在→无法外溢→找不到需求者） | **外溢 → 被发现 → 回流原平台**，闭环打通 |

## 四、核心机制设计（4 个）

### 机制 1：外链发布（一条"发现"= 一个外链）
- 发布内容 = 标题 + 描述 + **外链 URL** + **来源平台** + 类型 + 标签；
- 所有内容必须指向原平台，引力不站内托管内容；
- 卡片「查看」→ 新标签页跳转原平台外链。

### 机制 2：商业透明声明（用户强调的"交易提醒"）
- **发布时强制声明**：是否含佣金 / 返佣 / 付费推广；含则填写佣金说明（如"分享得 30% 分佣"）；
- **展示时显著标注**：商业内容卡片带「推广」徽标 + 佣金说明小字；
- **详情/浏览时统一提示**："本内容可能含推广链接，交易与交付在原平台完成，请自行判断"；
- 这是**秩序与信任的地基**，也是合规要求（杜绝隐性营销）。

### 机制 3：回流原平台（引力不碰交易）
- 点击「查看」→ 跳原平台，交易/订阅/返佣在原平台完成；
- 引力不做支付、不托管内容、不担保交易；
- 平台声明贯穿：发布流程提示 + 页脚免责 + 详情页提示。

### 机制 4：秩序与展示（引力职责）
- **展示规则**：类型分类、商业标注、内容规范（合法、真实、不侵权）；
- **秩序规则**：未来接后端后做审核/举报/下架；mock 阶段为展示规则 + 声明；
- **边界声明**：引力只做展示与连接，内容哪里发布、交易与交付由原平台负责。

### 机制 5：广场 = 讨论层（2026-08-21 已实施）
- 广场不承接内容展示（避免与发现流重复），而是**围绕内容的讨论场**：讨论好坏、求助、组队、推广经验交流；
- **帖子内容支持贴外链**（URL 自动解析为可点击链接，`LinkifiedText`）——发帖即可关联任何发现内容，形成「发现 → 讨论 → 转化」闭环；
- 列表卡对含外链的帖子显示「含链接」标记；详情页正文 URL 渲染为可点击外链（新标签页打开）。

## 五、信息架构落点（在现有四结构上增强）

| 结构 | 承载 |
|---|---|
| **首页** | 公告 + 为你推荐（高价值发现，商业内容透明标注） |
| **发现** | 全量外链内容流 + 筛选（**类型 + 商业属性**） |
| **分类** | 按方向浏览（工具 / 课程 / 作品 / 服务 / 活动…） |
| **广场** | 围绕内容的交流（求助、组队、讨论——承接"求推荐""组队参加大会"） |
| **发布**（弹窗） | 增强为完整外链发布：标题 / 描述 / 外链 URL / 来源平台 / 类型 / **商业声明** |

## 六、数据模型扩展

```ts
/** 一条"发现"（外链展示） */
interface DiscoveryItem {
  type: string;             // 内容类型
  title: string;
  description: string;
  source: string;           // 推荐人 / 来源
  tags: string[];
  url?: string;             // 原平台外链（新增）
  origin?: string;          // 来源平台：微信 / 知乎 / CSDN / FlowUs / 博客 / 活动（新增）
  commercial?: boolean;     // 商业推广（已有）
  commission?: string;      // 佣金说明，如「分享得 30% 分佣」（新增，commercial 时必填）
}
```

**mock 数据补齐方向**（对应真实场景样例）：
- 普通内容：微信文章 / 知乎回答 / 个人博客（url + origin）
- 商业推广：FlowUs 专栏 30% 分佣 · VPN 10% 返佣 · 3D 订阅 20% · trae 积分活动（url + origin + commercial + commission）

## 七、页面与交互设计要点

1. **发布弹窗增强**（现有 app-shell 发布弹窗）：增加外链 URL、来源平台下拉、**商业属性开关**（开则显示佣金说明输入）；
2. **发现卡片**：商业内容显著「推广」徽标 + 佣金说明小字；普通内容显示来源平台（如"来自 知乎"）；
3. **发现筛选**：类型 chips 之外增加「全部 / 普通 / 推广」过滤；
4. **详情页**（复用广场详情模式）：完整内容 + 原平台跳转按钮（醒目）+ 商业提示 + 评论区；
5. **全站交易提示**：页脚免责声明升级为业务声明（"引力只做展示与连接…"）。

## 八、规则体系（秩序）

| 编号 | 规则 |
|---|---|
| R-1 | 内容必须为外链，指向原平台；引力不托管内容 |
| R-2 | 商业内容（含佣金/返佣/付费）**必须声明并标注**，隐瞒视为违规 |
| R-3 | 引力不参与交易、不担保；交易与交付由原平台负责 |
| R-4 | 展示秩序：合法、真实、不侵权；接后端后启用审核/举报/下架 |
