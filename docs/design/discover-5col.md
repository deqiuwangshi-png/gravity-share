# 发现页一行五列布局 · 方案

> 版本：v1.2 · 日期：2026-08-21 · 状态：**✅ 已确认并实施（含 UX 改良 v1.2：4 列 + 标签分层 + 统一底部）**
> 范围：发现页卡片网格（5 列 → 4 列自适应）+ 发现详情页 + 卡片 UX 改良

---

## 一、可行性结论

**可行，但有硬前提**：5 列 = 卡片大幅变窄，必须配套 **① 卡片紧凑化** + **② 自适应列数**，否则内容挤压、观感崩坏。

### 尺寸测算

| 项 | 数值 |
|---|---|
| 发现页中栏宽度（保持右栏 280px） | ≈ 868px |
| 5 列每列（gap 12） | ≈ **(868 − 4×12) / 5 ≈ 164px** |
| 卡片内衬（12px×2）后内容区 | ≈ 140px |
| 可容纳 | 标题 2 行 · 描述 2 行（截断）· 标签 1-2 个 |

> 164px 宽的卡片是"紧凑图块"级别（类似电商 5 列商品卡），**不适合放完整描述**，必须压缩内容形态。

---

## 二、布局方案（核心）

### 2.1 网格：自适应列数，中栏正好 5 列

```css
.discovery-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(150px, 1fr));
  gap: 12px;
}
```

- 中栏 868px → `floor((868+12)/(150+12)) = 5` 列 ✓；
- **无需固定断点**：视口变窄（1100px 以下右栏隐藏、800px 以下单栏）时，auto-fill 自动降为 4→3→2→1 列；
- 移除现有固定 `repeat(3,1fr)` 及 1100px/800px 的列数覆盖。

### 2.2 卡片紧凑化（DiscoveryCard）

| 项 | 现值 | 5 列紧凑值 |
|---|---|---|
| padding | 18px | **12px** |
| 标题字号 | 16px | **14px**（2 行截断） |
| 描述 | 完整多行 | **11px · 2 行截断** |
| tags | 全部显示 | **最多 2 个** |
| 底部来源+查看 | 两栏 | **仅保留来源行（或收起"查看"）** |
| 推广标识 | 徽标+佣金说明 | 保留「⚠ 推广」徽标，佣金说明收进详情 |

> 卡片仍是 DiscoveryCard（组件复用），仅样式与结构微调；首页"为你推荐"若共用 `.discovery-grid` 将同步变化——**待确认是否统一**。

## 四、风险与权衡

| 点 | 说明 |
|---|---|
| 信息密度 ↑ | 一屏看更多候选，浏览效率提升（电商式） |
| 单卡内容 ↓ | 描述截断严重，标题挤占——需要接受"看图块找线索，点进详情看全文"的心智 |
| 详情页入口 | 紧凑卡更依赖点击详情，建议后续做发现详情页（/discover/[id]）承接 |
| 右栏保留 | 保持列表页两栏一致性（V2 规则），5 列在 868px 中栏实现 |
