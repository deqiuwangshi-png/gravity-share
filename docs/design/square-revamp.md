## 一、定稿：发布三入口

| 入口 | 定位 | 发布去向 | 形态 |
|---|---|---|---|
| **A · 推荐好东西** | 随手写推荐外链资源 | **发现流** | 沉浸式（正文 + 发布） |
| **B · 推广外链（带分佣）** | 推广/引流/分销，合规保护 | **发现流**（强制官方标识 + 佣金条件） | 随手写 + 推广类型 + 佣金条件 |
| **C · 话题帖子**（新增） | 广场发帖：讨论/求助/找方案/交易信息 | **广场**（开放话题流） | 沉浸式（正文 + 可选外链 + #标签） |

**Step 1 三入口选择**：推荐好东西（✦）/ 推广外链（◉）/ 话题帖子（▤），后接各自表单。

**职责分离**：A/B → 发现流（资源索引），C → 广场（交流场）。C 入口出现后，**A 不再双展示进广场**（避免同一内容两处重复），广场内容由 C 入口承载。

---

## 二、广场定位升级：开放场

> **广场 = 大家都能看到、都能交易的开放场——讨论、求助、找解决方案、找东西、找人，都不该限制。**

| 属性 | 设计 |
|---|---|
| 公开 | 所有话题所有人可见（无门槛浏览） |
| 开放 | **领域不设限**：领域胶囊（我的领域 + 探索领域，打破孤岛）；**内容形态不设限**：讨论/求助/方案/交易信息 |
| 交易 | 话题可带外链（解决方案/商品/服务）；交易与交付回流原平台，引力只做秩序与展示 |
| 找方案 | 领域胶囊筛选 + 话题流（#标签即领域） |

**三找人**：人找东西（发现资源）· 东西找人（推广触达）· 人找人（求助/对接）——广场承载后两者，发现流承载前两者。

## 三、入口 C 话题帖子设计

```
┌────────────────────────────────┐
│  发布话题              ×        │
│  [ 说点什么…（求助/讨论/       ]│  ← 沉浸式正文（与 A 同款心智）
│  交易信息都行）…               │
│  [ 可选：贴一个链接  ]         │  ← 可选外链（方案链接等）
│  [#设计] [#求助] #添加…        │  ← #标签即领域（配合广场胶囊）
│          [ 发布 ]              │
└────────────────────────────────┘
```

- 发布 → 广场话题池（SquarePost：author/content/tags/可选 url）；
- 标签即领域：`#设计` `#求助` `#出售`——广场领域胶囊按 tags 筛选；
- 交易表达：正文写清需求/条件，可带链接，不设结构化交易字段（极简 + 事后审核兜底）。

**业务流闭环（发布 → 浏览 → 转化）**：
1. **冷启动**：A/C 随手写低门槛 → 发现流与广场快速有内容；
2. **转化**：B 推广 → 官方标识 → C 端信任 → 回流原平台交易；
3. **生态**：C 话题 → 广场讨论/求助 → 领域胶囊探索（打破孤岛）→ 找到方案/东西/人；
4. **秩序**：推广强制标识 + 事后审核 + 引力不碰资金（交易永远在原平台）。
