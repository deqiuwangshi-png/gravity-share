# 广场「列表 + 详情」两级结构 · 方案

> 版本：v1.1 · 日期：2026-08-21 · 状态：**✅ 已确认并实施**（方案 A：去右栏 + V2 补充条款）
> 承接：docs/design/navigation-square-redesign.md（四结构导航已实施）

---

## 一、概念定位（"这个该如何说"）

广场采用业界通用的 **「话题流 + 详情页」两级结构（Feed → Detail）**：

> **列表出摘要，点击看全文；详情页承载完整内容与互动（评论 / 点赞 / 浏览）。**

- **列表页 `/square`**：紧凑摘要流，一屏看多条话题，承担「浏览与发现」；
- **详情页 `/square/[id]`**：完整话题正文 + 互动数据 + 评论区，承担「阅读与参与」。

类比：微博时间线 → 微博正文页；贴吧列表 → 帖子详情；知乎热榜 → 问题页。

---

## 二、信息架构

```
/square                话题列表（紧凑卡：头像 / 用户名 / 内容摘要 / 轻量元信息）
  └─ /square/[id]      话题详情（完整内容 + 点赞/浏览 + 评论区）
```

- 列表卡整卡可点（`Link`）→ 详情；
- 详情页顶部「← 返回广场」；
- 无效 id → `notFound()` 404。

## 三、列表紧凑卡设计（当前帖卡的简化版）

```
┌───────────────────────────────────┐
│ [◯山] 山川 · 10 分钟前             │ ← 头像 30px + 用户名 + 时间（一行）
│ 整理了一份独立开发者常用的工具清单，   │ ← 内容摘要（截断 2 行，超出省略）
│ 从设计、开发到部署全覆盖…            │
│ 赞 24 · 评论 6 · 浏览 128          │ ← 轻量元信息行（灰字小字）
└───────────────────────────────────┘
```

**与当前的差异（简化点）**：

| 维度 | 当前帖子卡 | 紧凑列表卡 |
|---|---|---|
| 内容 | 全文展示 | 截断 2 行 |
| 标签 chips | 展示 | **去掉**（详情页才看） |
| 页脚赞/评论 | 左右两栏 | 合并为一行「赞 · 评论 · 浏览」 |
| 头像 | 34px | 30px |
| 内边距 | 18-20px | 12-14px |
| 卡片间距 | 14px | 10px |

## 四、详情页设计（/square/[id]）

```
┌────────────────────────────────────┐
│ ← 返回广场                           │
│ [◯山] 山川 · 10 分钟前              │
│ 整理了一份独立开发者常用的工具清单，    │ ← 完整正文
│ 从设计、开发到部署全覆盖，分享给大家。  │
│ #独立开发  #工具                     │ ← tags（轻量保留）
│ ────────────────────────────────   │
│ 赞 24 · 浏览 128                    │ ← 互动条（点赞可点）
│ ────────────────────────────────   │
│ 评论 6                              │
│ [说点什么…________________][发布]    │ ← 评论输入（mock 提交）
│ [◯林] 林间 · 1 小时前                │
│  说得太好了，收藏了                   │ ← 评论列表（静态 mock）
└────────────────────────────────────┘
```

**布局决策**：详情页为阅读型页面，**去掉右栏（AppAside）**，保留左侧导航壳（AppShell）保证页面间可切换。

## 五、数据模型扩展

```ts
/** 广场帖子（扩展：新增浏览量） */
interface SquarePost {
  id: string;
  author: string;
  content: string;    // 完整正文；列表用 CSS 截断 2 行（不单独存摘要）
  tags: string[];
  likes: number;
  comments: number;
  views: number;      // ← 新增
  time: string;
}

/** 广场评论（新增） */
interface SquareComment {
  id: string;
  postId: string;     // 归属帖子
  author: string;
  content: string;
  time: string;
  likes: number;
}
```

- `squarePosts` 补 `views` 字段（mock）；
- 新增 `squareComments`（每帖 2-3 条 mock）；
- 详情页取数：`findPost(id)` + `getComments(postId)`（lib/data.ts 内工具函数）。
