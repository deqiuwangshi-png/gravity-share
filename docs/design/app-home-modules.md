## 十一、发现页布局重构方案（UI 设计分析，待确认）

> 背景：用户中心弹窗模式取消（回退）；发现页三栏布局经 UI 分析不合理，需重构。

### 11.1 当前三栏的问题诊断（UI 视角）

| # | 问题 | 说明 |
|---|---|---|
| 1 | **核心内容被挤压** | 公告走马灯占首屏最顶，优先于核心 Feed（为你发现）——活动信息不该压过产品主内容 |
| 2 | **卡片过宽** | 中栏 ~850px 排 2 列，每卡 ~418px，远超易读宽度（300–380px），文字拉伸难读 |
| 3 | **右栏是"杂物间"** | 探索领域 + 热门发现 + 品牌横幅三个小卡垂直堆叠，无主次、视觉噪音 |
| 4 | **浏览入口错位** | 分类（探索领域）是高频浏览入口，放右栏小列表价值低；应回主内容区顶部 |
| 5 | **层级失衡** | 辅助信息（热门/横幅）与核心内容同屏竞争注意力 |

### 11.2 目标布局：双栏重构（删右栏）

```
┌───────────┬────────────────────────────────┐
│ 左栏 230px │ 顶栏：⌕ 搜索 … ✉ [U]            │
│ [Logo]    │────────────────────────────────│
│ + 发布    │ 探索领域（8 分类：2×4 网格）      │ ← 浏览入口回归
│ 探索导航   │ 为你发现（3 列卡片网格）          │ ← 核心 Feed 最大化
│           │────────────────────────────────│
│           │ 公告走马灯（窄条，Feed 下方）      │ ← 活动信息降级
└───────────┴────────────────────────────────┘
```
