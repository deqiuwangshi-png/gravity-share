# 个人主页（/profile）重构 · 方案

> 版本：v2.0 · 日期：2026-08-21 · 状态：**✅ 已确认并实施**
> 承接：user-menu「个人主页」入口（原为 settings-panel 的 profile 面板 → 升级为独立页面）

---

## 一、可行性结论

**可行。** 数据层已就绪（author / note / publishTime / url / 推广标识），只需：

- 新建路由 `app/(app)/profile/page.tsx`（中间栏承载，保留 AppShell 侧边栏 + AppAside 右栏——**三栏骨架一致，符合 V2**）；
- 两个组件：ProfileTabs（胶囊导航 client）+ ProfilePost（Twitter/X 风格帖子卡）；
- 一个样式文件 `styles/app/profile.css`；
- 入口改造：user-menu「个人主页」从面板改为跳转 `/profile`。

### 区块明细

| 区块 | 实现 |
|---|---|
| 封面 | 宽幅色块占位（mock 无图，接后端换真实封面 URL）；右上角【更换封面】= 占位动作（`data-placeholder`） |
| 头像重叠 | 88px 圆头像，`margin-top` 负值上叠封面与内容区之间（白描边 3px 分离） |
| 编辑个人资料 | 头像右侧按钮，占位动作（mock） |
| 昵称 + 简介 | 大号加粗昵称；简介 = **浅灰底无边框块**（按你备注去掉虚线） |
| 数据组 | 发布（动态计算 = 我的发布数）/ 点赞 186 / 关注 52（mock） |
| 胶囊导航 | 发现 \| 推广 \| 收藏 \| 设置；选中项绿色下划线（`--primary`），client 切换 |
| 帖子流 | Twitter/X 风格：头像 + 昵称 + 时间 + 正文 + 正文下圆角链接预览卡（左小图 + 右标题/摘要，整卡可点） |

### Tab 内容

| Tab | 内容 |
|---|---|
| **发现**（默认） | 我的发布列表（`author === "我的账户"`，含本会话新发布） |
| **推广** | 我的发布中 `commercial` 的内容（带 ⚠ 标识） |
| **收藏** | 空态占位「还没有收藏」 |
| **设置** | 占位说明「账户与偏好设置已迁移至头像菜单」 |

## 三、数据准备

- **当前用户**：昵称「我的账户」（与发布内容 `author` 一致，诚实展示）；bio「在引力分享好东西的人……」
- **发布数**：`getDiscoveryItems().filter(i => i.author === "我的账户").length`（动态）
- **mock 补充**：`data.ts` 补 2 条 `author: "我的账户"` 的发现内容（1 普通 + 1 推广），让个人主页首屏有内容，发现流同步可见（即"自己发布的东西"）
