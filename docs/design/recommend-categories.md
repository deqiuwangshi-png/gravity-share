# 推荐页 + 全部分类页 布局设计方案

> 状态：待确认 · 路由：`/recommend`、`/categories`（侧边栏「推荐」「全部分类」接通）

## 一、页面骨架（两页共用）

两页都放在 `app/(app)/` 下，**复用发现页的三栏布局**（`.app-layout`：中栏内容流 + 右栏辅助），侧边栏/顶栏由 AppShell 提供：

```
app/(app)/
├── recommend/page.tsx      推荐 /recommend
└── categories/page.tsx     全部分类 /categories
```

右栏三件套（探索领域 3 列网格 / 热门发现 / 品牌横幅）两页复用——与 /home 完全一致，保证跨页布局统一。
