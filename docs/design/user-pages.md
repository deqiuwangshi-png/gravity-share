## 四、行结构（键值对规范）

```
[ 名称（左对齐） ] —— [ 当前值（灰字） ] —— [ 操作按钮（右对齐） ]
```

- 操作按钮：主色幽灵按钮 / 绿色文字链接（`var(--primary)`），如"修改 / 编辑 / 管理 / 开启"
- 危险操作（永久删除账号）：`>` 箭头 + `var(--error)` 暗红
- 行间分隔：1px `var(--border)`（#E5E9E7），左右留 8px 边距
- 每行左右两端对齐（`justify-content: space-between`）

## 五、交互

| 交互 | 行为 |
|---|---|
| 打开 | 点击用户菜单 4 项之一 → 打开面板并选中对应 tab |
| 切换 | 面板内左侧导航点击切换右栏内容（不重开） |
| 关闭 | 遮罩 / × / Esc |
| 样式 | 白色 `var(--surface)`、文字 `--foreground`/`--text-muted`、圆角 8–12px、淡阴影 `0 8px 24px rgba(0,0,0,0.05)` |
